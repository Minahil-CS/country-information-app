# 🌍 TerraScope — Country Information & Global Explorer

An advanced, responsive **Country Information Web Application** built using **HTML5, CSS3, and Vanilla JavaScript**. TerraScope allows users to explore detailed geopolitical, demographic, and geographic insights for countries worldwide with real-time search, region filtering, favorites persistence, and side-by-side country comparisons.

🔗 **Live Demo:** [View Live Application](https://YOUR-USERNAME.github.io/terrascope-country-info-app/)

---

## ✨ Key Features

- **🌐 Live API + Resilient Offline Fallback:** Fetches real-time nation data from the REST Countries API with an automatic 8-second timeout and seamless fallback to an embedded dataset if offline or rate-limited.
- **🔍 Debounced Instant Search:** Search effortlessly by country name, capital city, or ISO-3 country code.
- **🗺️ Region Filtering & Multi-Criteria Sorting:** Filter by continent (Africa, Americas, Asia, Europe, Oceania) and sort dynamically by Name, Population, or Land Area.
- **📑 Interactive Country Dossier Modal:** View high-resolution flags, official coats of arms, native names, subregions, currencies (with symbols), spoken languages, timezones, population density, clickable neighboring border countries, and direct Google Maps links.
- **⚖️ Side-by-Side Country Comparison:** Compare any two countries across key metrics (population, area, density, capital, currency, and region) in a dedicated comparison view.
- **⭐ Persistent Favorites & Theme Toggle:** Bookmark favorite countries using `localStorage` and switch smoothly between **Dark Mode** and **Light Mode** with a modern glassmorphism interface.
